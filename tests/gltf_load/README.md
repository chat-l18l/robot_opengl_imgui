# gltf_load — the glTF loader

Checks that `rbt_gltf_load()` turns a glTF file into the right joints, meshes
and visuals, and that the result moves as the file says it should.

A loader can produce something that renders plausibly and still be wrong in
ways no screenshot shows: a joint on the wrong parent, an axis not normalised,
limits read into the wrong fields. So the test runs against files generated by
`tools/make-test-models.py`, where every answer is known in advance, and the
expected end-effector positions are worked out by hand in the test's comments
rather than computed by the code under test.

## What it covers

| File | Checks |
|------|--------|
| `models/test_arm.glb` | One frame per node in depth-first order, parents before children, child counts; principal, slanted and negative axes; limits and default angle; a mesh shared by two nodes loaded once and drawn twice; 16-bit indices; normals computed for a primitive that has none; base colours encoded to sRGB |
| `models/test_arm.glb` | Forward kinematics at rest, through a principal axis, and through a slanted axis inside a frame the file rotates with a quaternion |
| `edge_cases.gltf` | Swapped limits put right, a zero axis replaced by +Z, a default clamped into its limits, an unsupported joint type left fixed, a string value spelling a key name not mistaken for that key, absent fields at their documented defaults |
| missing, `no_geometry.gltf`, non-glTF | Refused, with the current robot left untouched |

## Running

```bash
pixi run test
```

The binary prints one line per check and exits non-zero on any failure:

```bash
./build/tests/gltf_load/gltf_load_test
```

The repairs print warnings to stderr while the test runs; they are expected.

## Regenerating the test files

```bash
pixi run test-models
```

The generator is deterministic, so running it without changing it leaves git
clean. Change it, and the expectations in `gltf_load_test.cpp` have to follow.

## Mutation-checked

Each of these changes to `src/gltf_load.cpp` fails the test:

| Change | Checks that fail |
|--------|------------------|
| Axis not normalised | Slanted axis normalised; axis labels; slanted-axis kinematics |
| Swapped limits not put right | Swapped limits |
| Key scanner no longer requires a `:` after the key | A value spelling a key name |
| Node rotation dropped, translation kept | Slanted-axis kinematics; the shared finger mesh |
| Every node treated as a root | Parent structure and all kinematics |
